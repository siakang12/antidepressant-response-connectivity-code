Statistical analysis code for a resting-state functional connectivity study of antidepressant response in major depressive disorder.

# Analysis code for antidepressant response functional connectivity study

This repository contains analysis scripts used for the manuscript:

"Altered Somatosensory-Interoceptive Network Connectivity in Pain-Processing Hubs Differentiates Antidepressant Responders from Non-Responders in Major Depressive Disorder"

The scripts include:
- sensitivity analysis controlling for baseline depression severity
- group-by-score interaction analysis
- head motion and scrubbing metric extraction

Raw imaging and clinical data are not publicly shared because of institutional and ethical restrictions.
